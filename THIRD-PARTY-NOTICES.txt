MonetUI - third-party components
================================

MonetUI's own code, textures and icons are original work by EastHillGu,
released under the MIT License (see LICENSE).

The following components are made by others and included under their own
licenses. Anything not listed here ships with no third-party material:
every texture under Assets/Textures/ is generated by this project's own
scripts (tools/regen-textures.js, tools/svg/*.svg, the GIMP scripts) or drawn
by hand.

Libraries (Libs/)
- LibStub - public domain. Included unmodified.
  See Libs/NOTICE.md.
- LibMonetColor-1.0, LibMonetColor-Anim-1.0, MonetColorMapData-1.0 - built from
  the author's own "monetcolors" project (github.com/easthillgu/monetcolors),
  not third-party code. They are bundled only so the add-on needs no separate
  download. See Libs/NOTICE.md.
- No action-bar library, no Ace3 and no LibSharedMedia are used: action buttons
  are drawn directly on the client's SecureActionButtonTemplate, and fonts /
  textures are shipped with the add-on.

Fonts (Assets/Fonts/)
- Pingfangpixel.ttf - "Dianzhen Pingfang" (点阵苹方) by DynaComware, derived from
  PingFang, a typeface licensed by Apple Inc. The file carries NO license of its
  own and therefore MUST NOT be redistributed. This build ships it for private
  use only; remove it before any public release or upload.
- fusion-pixel-12.ttf - Fusion Pixel Font 12px, Copyright (c) 2022 TakWolf,
  SIL Open Font License 1.1, full text in Assets/Fonts/OFL-FusionPixel.txt.
  Redistributable; currently unused and kept as the licensed fallback.
- super-effective.ttf - Super Effective v1.0, (c) 2012 The Ender (FontStruct),
  CC BY-SA 3.0 (http://creativecommons.org/licenses/by-sa/3.0/) - attribution
  required, and the font file itself is redistributed under the same license.
  Used for cooldown digits only.
- roadway.ttf - Roadway, (c) 2005 Keith Bates / K-Type Freebie. The file carries
  no license statement; it is not referenced by the code and is kept only as a
  rollback copy, not redistributed.

See Assets/Fonts/NOTICE.md for the per-file provenance table.

Reference only - NOT included
- Andromeda (GPL-3.0) and EllesmereUI were read as reference implementations to
  learn behaviour and layout ideas. No source file, texture or font from either
  project is included in MonetUI.
- Blizzard's own FrameXML/UI source is not included either: the add-on only calls
  the client's Lua API and restyles frames the game creates at runtime.

World of Warcraft, WoW, Warcraft and their logos are trademarks of Blizzard
Entertainment, Inc. MonetUI is a fan-made add-on, not made or endorsed by
Blizzard.
